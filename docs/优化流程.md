# 架构演进记录

早期设计曾参考 MongoDB，当前实现已统一为 MySQL + JPA。

## 演进目标

- 从服务端模板渲染演进为 Spring Boot REST API + React SPA。
- 从脚本式启动整理为 Docker Compose 编排 MySQL、Redis、后端和前端。
- 从分散的权限判断整理为基于 Spring Security、JWT、UserPrincipal 和服务层校验的鉴权模型。
- 从粗略输入处理补强为文章/评论 HTML 清洗、敏感词检查和基础限流。

## 当前实现重点

- 后端按 `Controller -> Service -> Repository -> Entity` 组织。
- 数据层使用 MySQL 表结构、JPA Entity 和 Repository 查询。
- Redis 用于 Token 黑名单和接口限流。
- Nginx 代理 `/api` 并提供 SPA fallback。
- GitHub Actions 做后端测试和前端构建检查。

## 后续优化方向

- 引入数据库迁移工具管理 DDL。
- 补充接口集成测试和端到端测试。
- 对部署链路增加镜像发布、环境变量管理和回滚流程。
- 对前端编辑器、登录态刷新和管理后台增加更多测试。
